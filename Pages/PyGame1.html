1. Основы библиотеки

PyGame — это набор инструментов для создания игр на языке Python. В основе любой игры лежит Игровой цикл (Game Loop).

📝 Задание в тетрадь №1:

Запишите определение: Игровой цикл — это бесконечный цикл, который отвечает за обработку нажатий клавиш, расчет движения объектов и отрисовку картинки на экране.

2. Настройка Thonny

Чтобы библиотека работала, её нужно установить в Thonny:

  1. Откройте меню Инструменты (Tools) -> Управление пакетами (Manage packages).
  2. В строке поиска введите pygame.
  3. Нажмите кнопку Install и дождитесь окончания загрузки.

3. Базовый шаблон программы

Скопируйте этот код в Thonny и запустите его (клавиша F5). Это основа вашей будущей игры.

import pygame

# 1. Инициализация
pygame.init()

# 2. Настройка экрана
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Моя первая игра")

# 3. Цвета (RGB)
WHITE = (255, 255, 255)
BLUE = (0, 0, 255)

# 4. Позиция игрока
player_pos = [400, 300]
clock = pygame.time.Clock()

running = True
while running:
    # А) Обработка событий (выход)
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # Б) Логика (движение)
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  player_pos[0] -= 5
    if keys[pygame.K_RIGHT]: player_pos[0] += 5
    if keys[pygame.K_UP]:    player_pos[1] -= 5
    if keys[pygame.K_DOWN]:  player_pos[1] += 5

    # В) Отрисовка
    screen.fill(WHITE) 
    pygame.draw.rect(screen, BLUE, (player_pos[0], player_pos[1], 50, 50))
    
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Самостоятельно напишите условие для правого края (учитывая, что ширина экрана WIDTH равна 800).
