Рабочий лист №1: Введение в базы данных

По материалам пособия «Работа в Access 2010»

1. Основные понятия

База данных (БД) — это представленная в объективной форме совокупность материалов, систематизированных таким образом, чтобы эти материалы могли быть найдены и обработаны с помощью ЭВМ.

СУБД (Система управления базами данных) — это комплекс программных средств, предназначенных для создания структуры новой базы, наполнения ее содержимым, редактирования содержимого и визуализации информации.

2. Структура таблицы

Данные в Access хранятся в таблицах. Таблица состоит из столбцов и строк:

Понятие Описание Аналогия
Поле Элементарная единица логической организации данных, соответствующая неделимой единице информации. Столбец таблицы
Запись Совокупность логически связанных полей, описывающих свойства одного объекта. Строка таблицы
📝 Задание для выполнения:

Открой рабочую тетрадь, запиши дату и тему урока. Перепиши в тетрадь определения следующих терминов:

  1. База данных (БД)
  2. СУБД
  3. Поле таблицы
  4. Запись таблицы

Подсказка: используй текст из блоков выше. Пиши аккуратно, выделяй термины подчеркиванием.
